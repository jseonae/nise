# 데이터 파일

화면에 뿌리는 데이터를 엑셀로 관리합니다. 엑셀을 고친 뒤 변환 명령을 한 번 실행하면 화면이 읽는 JSON 이 다시 만들어집니다.

## 조사 변천사 (`survey_history.xlsx`)

| 무엇 | 어디 |
|---|---|
| 엑셀 원본 | `_data/survey_history.xlsx` |
| 변환 스크립트 | `_tools/build_survey_history.py` |
| 만들어지는 데이터 | `kr/data/survey_history/index.json`, `round_차수.json` (직접 고치지 않습니다) |
| 화면 | `kr/html/stat/survey_history_list.html`, `survey_history_view.html?id=번호` |
| 그리는 스크립트 | `kr/js/survey-history.js` |

### 고치는 순서
1. `_data/survey_history.xlsx` 를 고치고 저장합니다.
2. 저장소 폴더에서 `python3 _tools/build_survey_history.py` 를 실행합니다. (맥 기본 파이썬으로 실행되며 설치할 것이 없습니다)
3. `완료 : 차수 N개, 조사대상자 N종` 이 나오면 브라우저에서 확인하고 커밋합니다.
   잘못 적힌 줄이 있으면 `[시트 이름] 몇 번째 줄 : 무엇이 문제` 라고 알려 주고 멈춥니다.

### 시트
- **차수** : 탭과 개요. 한 줄이 한 차수입니다. `상태`가 `예정`이면 탭만 보이고 눌리지 않습니다.
- **조사대상자** : 목록의 카드, 상세 화면의 제목. `번호`가 상세 주소(`?id=번호`)가 됩니다. 차수×100+순서(예 603)로 매기고, 한 번 정한 번호는 바꾸지 않습니다.
- **문항** : 상세 화면 표의 행. `번호`는 조사대상자 시트의 번호입니다.

제목 줄(첫 줄)의 열 이름은 바꾸지 않습니다. 열 이름에 마우스를 올리면 적는 방법이 메모로 나옵니다.

### 자동으로 계산되는 것 (엑셀에 적지 않음)
- 조사대상자별 문항 수 = 문항 시트의 `문항수` 합계. 영역별 문항수가 없는 차수(제2~4차)만 조사대상자 시트의 `문항수`에 전체 수를 적습니다.
- 영역 수, 묶음의 `2종`, 요약 문구(`조사 대상자 8개·영역 50개·총 421문항`), 이전글 · 다음글

### 새 차수 추가
1. 차수 시트에 한 줄 추가 (이미 `예정`으로 있으면 `공개`로 바꿈)
2. 조사대상자 시트에 그 차수의 대상자를 추가 (번호 701, 702 …)
3. 문항 시트에 대상자별 영역 줄을 추가
4. 변환 명령 실행. HTML 은 고치지 않습니다.
