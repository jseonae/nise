2026년 특수교육 실태조사 데이터 활용 시스템 개통 안내

공지 조회수 : 4859 2025.09.08

국립특수교육원은 특수교육 실태조사 결과를 누구나 쉽게 찾아볼 수 있도록 「특수교육 실태조사 데이터 활용 시스템」을 개통합니다.

1. 개통일
2026. 8. 25.

2. 제공 서비스
- 특수교육 현황 : 2008~2025년 특수교육대상자 수와 특수교육기관 수 추이
- 시계열 시각화 : 조사 연도별 실태조사 결과 비교
- 핵심데이터 시각화 : 연도별 주요 특수교육 데이터 그래프
- 자료실 : 실태조사 보고서와 통계·정책 자료 내려받기

3. 문의
국립특수교육원 (담당 부서·연락처 확정 후 표기)

붙임 :
특수교육 실태조사 데이터 활용 시스템 이용 안내
