# 조사 변천사 데이터

조사 변천사 화면(목록 · 상세)은 이 폴더의 **엑셀 파일 하나**를 읽어서 그립니다.
엑셀 파일만 바꿔 올리면 화면이 바뀝니다. 따로 변환하거나 실행할 것이 없습니다.

| 무엇 | 어디 |
|---|---|
| 데이터(엑셀) | `kr/data/survey_history/survey_history.xlsx` |
| 화면 | `kr/html/stat/survey_history_list.html`, `survey_history_view.html?id=번호` |
| 엑셀을 읽는 스크립트 | `_common/resources/js/cm-xlsx.js` |
| 화면을 그리는 스크립트 | `kr/js/survey-history.js` |

## 내용을 바꾸는 순서
1. `survey_history.xlsx` 를 내려받아 고치고 저장합니다. **파일 이름과 형식(.xlsx)은 그대로** 둡니다.
2. **개발 서버**에 올린 뒤 아래 주소로 확인합니다.
   - 목록 : `…/kr/html/stat/survey_history_list.html?check=1`
   - 주소 끝의 `?check=1` 은 확인용입니다. 엑셀에 잘못 적힌 곳이 있으면 `[시트 이름] 몇 번째 줄 : 무엇이 문제` 인지 화면에 알려 줍니다.
3. 문제가 없으면 같은 파일을 **운영 서버**의 같은 위치에 올립니다. 올리는 즉시 반영됩니다.

> 엑셀에 잘못 적힌 곳이 있으면 일반 방문자에게는 화면 대신 "목록을 불러오지 못했습니다" 안내만 보입니다.
> 그래서 운영 서버에 올리기 전에 꼭 개발 서버에서 `?check=1` 로 확인해 주세요.

## 시트 (3개, 이름을 바꾸지 않습니다)
- **차수** : 탭과 개요. 한 줄이 한 차수입니다. `상태`가 `예정`이면 탭만 보이고 눌리지 않습니다.
- **조사대상자** : 목록의 카드, 상세 화면의 제목. `번호`가 상세 주소(`?id=번호`)가 됩니다.
  차수×100+순서(예 603)로 매기고, 한 번 정한 번호는 바꾸지 않습니다. (주소가 바뀌기 때문)
- **문항** : 상세 화면 표의 행. `번호`는 조사대상자 시트의 번호입니다.

첫 줄(제목 줄)의 열 이름은 바꾸지 않습니다. 열 이름에 마우스를 올리면 적는 방법이 메모로 나옵니다.
병합 셀은 쓰지 않습니다. 한 줄에 한 건씩 적습니다.

## 자동으로 계산되는 것 (엑셀에 적지 않음)
- 조사대상자별 문항 수 = 문항 시트의 `문항수` 합계.
  영역별 문항수가 없는 차수(제2~4차)만 조사대상자 시트의 `문항수`에 전체 수를 적습니다.
- 영역 수, 묶음의 `2종`, 요약 문구(`조사 대상자 8개·영역 50개·총 421문항`), 이전글 · 다음글

## 새 차수 추가
1. 차수 시트에 한 줄 추가 (이미 `예정`으로 있으면 `공개`로 바꿈)
2. 조사대상자 시트에 그 차수의 대상자를 추가 (번호 701, 702 …)
3. 문항 시트에 대상자별 영역 줄을 추가
4. 개발 서버에서 `?check=1` 로 확인한 뒤 운영 서버에 올립니다. HTML 은 고치지 않습니다.

## 알아 둘 점
- 방문자의 브라우저가 화면을 열 때마다 이 엑셀 파일을 내려받아 읽습니다. 그래서 **이 엑셀 파일은 누구나 내려받을 수 있습니다.**
  공개하면 안 되는 내용(메모, 숨긴 시트, 작업용 시트 등)은 넣지 않습니다.
- 암호가 걸린 엑셀, 옛 형식(.xls), 다른 이름으로 저장한 CSV 는 읽지 못합니다.
- 값은 글자 그대로 읽습니다. 수식은 엑셀이 마지막으로 계산해 둔 값이 쓰입니다.
