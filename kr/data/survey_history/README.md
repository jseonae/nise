# 조사 변천사 데이터

조사 변천사 화면(목록 · 상세)은 이 폴더의 **엑셀 파일 하나**를 읽어서 그립니다.
엑셀 파일만 바꿔 올리면 화면이 바뀝니다. 따로 변환하거나 실행할 것이 없습니다.

| 무엇 | 어디 |
|---|---|
| 데이터(엑셀) | `kr/data/survey_history/survey_history.xlsx` |
| 화면 | `kr/html/stat/survey_history_list.html`, `survey_history_view.html?id=번호` |
| 엑셀을 읽는 스크립트 | `_common/resources/js/cm-xlsx.js` |
| 화면을 그리는 스크립트 | `kr/js/survey-history.js` |

## 내용을 바꾸는 순서
1. `survey_history.xlsx` 를 내려받아 고치고 저장합니다. **파일 이름과 형식(.xlsx)은 그대로** 둡니다.
2. **개발 서버**에 올린 뒤 아래 주소로 확인합니다.
   - 목록 : `…/kr/html/stat/survey_history_list.html?check=1`
   - 주소 끝의 `?check=1` 은 확인용입니다. 엑셀에 잘못 적힌 곳이 있으면 `[시트 이름] 몇 번째 줄 : 무엇이 문제` 인지 화면에 알려 줍니다.
3. 문제가 없으면 같은 파일을 **운영 서버**의 같은 위치에 올립니다. 올리는 즉시 반영됩니다.

> 엑셀에 잘못 적힌 곳이 있으면 일반 방문자에게는 화면 대신 "목록을 불러오지 못했습니다" 안내만 보입니다.
> 그래서 운영 서버에 올리기 전에 꼭 개발 서버에서 `?check=1` 로 확인해 주세요.

## 엑셀 틀 (시트 이름은 바꾸지 않습니다)
평소에 고치는 곳은 첫 번째 시트 **[조사 변천사]** 하나입니다. 상세 화면의 표와 같은 모양으로 적습니다.
엑셀 파일 안의 세 번째 시트 **[작성 방법]** 에도 같은 안내가 들어 있습니다.

### [조사 변천사] 시트 : 한 줄 = 상세 화면 표의 한 줄(영역 하나)

| 연도 | 묶음 | 조사대상자 | 영역 | 세부 조사 문항 | 문항수 | 주석 | 대상자 전체 문항수 |
|---|---|---|---|---|---|---|---|
| 2023 | 보호자용 면접 조사 문항 | 특수교육대상자 보호자 | 일반사항 | 거주형태(2), … | 3 | | |
| | | | 교육 | 취학유예·유예 경험(3), … | 23 | | |
| | | 장애영아 보호자 | 일반사항 | 거주형태(2) | 2 | | |
| | 관리자 및 교사용 온라인 조사 문항 | 특수학교 관리자 | 일반사항 | 방과후학교 참여 현황, … | 5 | | |

- **연도 · 묶음 · 조사대상자는 바뀌는 첫 줄에만 적습니다.** 비워 두면 바로 윗줄과 같은 것으로 봅니다. (모든 줄에 다 적어도 됩니다)
- **연도** : 조사 연도. [연도] 시트에 있는 연도여야 합니다. 같은 연도는 한곳에 모아 적습니다.
- **묶음** : 목록에서 카드를 묶는 제목. 묶음이 없는 연도는 비워 둡니다.
- **조사대상자** : 목록의 카드 제목이자 상세 화면 제목. 연도나 묶음이 바뀌는 첫 줄에는 꼭 적습니다.
- **영역 / 세부 조사 문항 / 문항수 / 주석** : 상세 화면 표에 그대로 나옵니다. 영역 이름이 없으면 `-` 를 적습니다.
- **대상자 전체 문항수** : 영역별 문항수를 모를 때만, 그 대상자의 첫 줄에 전체 수를 적습니다. (지금 2011 · 2014 · 2017년이 이 경우)
- **줄 순서가 화면에 나오는 순서**입니다. 병합 셀은 쓰지 않고, 빈 줄은 무시됩니다.

### [연도] 시트 : 한 줄 = 한 연도(탭 하나). 연도가 새로 생길 때만 고칩니다
- **차수** : 제 몇 차인지 숫자만. **상태** : `공개` 또는 `예정`(탭만 보이고 눌리지 않음, [조사 변천사] 시트에 줄이 없어도 됨)
- **기준** : `대상자` 또는 `부문` (개요 문구가 "조사 대상자 8개" / "조사 부문 5개" 로 바뀜)
- **영역 이름** : 표 첫 칸의 제목, **묶음 단위** : 묶음 옆 "2종" 의 단위, **문항 단위** : `문항` 또는 `항목`
- **조사 부분** : 개요에 나오는 목록. 한 칸 안에서 Alt+Enter 로 줄을 바꿔 한 줄에 하나씩
- **안내** : 개요 아래 ※ 문구, **출처** : 자료 출처

## 자동으로 계산되는 것 (엑셀에 적지 않음)
- 대상자별 문항 수 합계, 영역 수, 묶음의 `2종`, 요약 문구(`조사 대상자 8개·영역 50개·총 421문항`), 이전글 · 다음글
- 상세 주소 번호(`?id=603`) : 차수×100 + 그 연도 안에서의 순서.
  **대상자 순서를 바꾸거나 중간에 끼워 넣으면 그 뒤 대상자의 주소가 바뀝니다.** 새 대상자는 되도록 그 연도의 맨 뒤에 추가하세요.

## 새 연도(차수) 추가
1. [연도] 시트에 한 줄 추가 (이미 `예정`으로 있으면 `공개`로 바꿈)
2. [조사 변천사] 시트 맨 아래에 그 연도의 줄을 적음 (연도 → 묶음 → 조사대상자 → 영역 순서로)
3. 개발 서버에서 `?check=1` 로 확인한 뒤 운영 서버에 올립니다. HTML 은 고치지 않습니다.

## 알아 둘 점
- 방문자의 브라우저가 화면을 열 때마다 이 엑셀 파일을 내려받아 읽습니다. 그래서 **이 엑셀 파일은 누구나 내려받을 수 있습니다.**
  공개하면 안 되는 내용(메모, 숨긴 시트, 작업용 시트 등)은 넣지 않습니다.
- 암호가 걸린 엑셀, 옛 형식(.xls), 다른 이름으로 저장한 CSV 는 읽지 못합니다.
- 값은 글자 그대로 읽습니다. 수식은 엑셀이 마지막으로 계산해 둔 값이 쓰입니다.
