색상 체계

색상 시스템은 주요 색상, 강조 색상, 그래픽 색상, 시스템 색상으로 구성된다. 색상(Hue)과 채도(Saturation)를 기준으로 명도(Lightness)를 13단계로 구분하며, Gray의 0(White)과 100(Black)을 제외한 색상은 11단계(5, 10~90, 95)로 구성된다.

색상 체계 구성: 구분, 토큰 이름, 용도
구분토큰용도
Gray--krds-color-light-gray-*중립적 정보와 배경, 구분선, 글자
Primary--krds-color-light-primary-*주요 상호작용 요소 (중요한 버튼, 링크 등)
Secondary--krds-color-light-secondary-*보조 상호작용 요소 (사이드 메뉴, 대부분의 UI 요소 등)
Accent--krds-color-light-point-*강조 요소로 제한적 사용 (새로운 알림, 중요 알림 배지 등). 토큰 이름은 point
Graphic--krds-color-light-graphic-*그래프, 배너, 일러스트 등 보조 요소
System--krds-color-light-{danger|warning|success|information}-*상태 전달. Danger 오류·위험, Warning 주의, Success 완료·긍정적 결과, Information 참고·안내
Alpha--krds-color-light-alpha-{black|white}*투명도. 배경(BG), 글자(Text), 선(Line)에 사용하며 글자는 배경과의 명암비를 고려

토큰 계층: 원시 색상(--krds-color-{mode}-*) → 의미 색상(--krds-{mode}-color-*) → 컴포넌트 변수. 화면에는 의미 색상 토큰을 사용한다.

명도 대비와 매직넘버

배경과 글자 색상의 명도 단계 차이(매직넘버)로 명도 대비를 보장한다. 예) 흰색(gray-0) 배경 위 본문 글자는 50단계 이상 차이 나는 색상을 사용한다.

매직넘버별 명도 대비와 사용 기준
매직넘버명도 대비사용 기준
403:1기본 모드 글자 최소 기준 (큰 텍스트 AA)
504.5:1기본 모드 본문 (일반 텍스트 AA)
707:1선명한 화면 모드 헤딩·레이블·아이콘 (일반 텍스트 AAA)
9015:1선명한 화면 모드 본문

아래 팔레트의 대비 값은 흰색(#ffffff) 배경 기준으로 foundation.js가 계산한 값이다. 3:1 미만은 회색으로 표시한다.

선명한 화면 모드 (High Contrast)

색상 대비를 높여 시각적 접근성을 강화한 모드다. <html data-krds-mode="high-contrast">로 전환하며, 어두운 배경에서 글자는 매직넘버 70(7:1), 본문은 90(15:1)을 기준으로 한다. 원시 색상 중 기본 모드와 값이 다른 것은 Secondary 팔레트뿐이고, 나머지는 같은 값을 의미 색상에서 다른 단계로 연결해 사용한다.

Secondary (high-contrast)

대비 값은 검정(#000000) 배경 기준이다.

의미 색상 (Semantic)

화면과 컴포넌트에 실제로 쓰는 토큰이다. 기본 모드는 --krds-light-color-*, 선명한 화면 모드는 같은 이름의 --krds-high-contrast-color-*를 사용한다. 각 칸에 참조하는 원시 색상과 최종 값을 표시한다.

사용 원칙

  • 색상 비율은 60-30-10 원칙을 따른다. 60%는 배경 및 중립적인 색상, 30%는 보조 색상, 10%는 주요 기능이나 중요 상호작용 색상이다.
  • 강조 색상(Accent)은 중요한 강조 요소에만 제한적으로 사용하며 최대 5%를 넘기지 않는다.
  • 색약자도 기능과 상태를 정확히 인지할 수 있도록 색상 외에 텍스트와 아이콘으로 정보를 보완한다.
  • 글자 색상은 기본 모드에서 최소 매직넘버 40, 본문은 50을 지킨다. 선명한 화면 모드에서는 70, 본문은 90(15:1)을 지킨다.
  • 본문 글자는 주로 그레이 계열을 유지하고, 주요 동작에는 primary, secondary, point, system 색상을 사용한다.
  • 투명도는 BG, Text, Line에 사용할 수 있으며, 텍스트는 가독성을 위해 배경과의 명암비를 고려한다.
  • 상호작용이 있는 요소의 상태 값은 점진적인 증가 또는 감소 규칙을 사용한다.
  • 화면 코드에서는 HEX 값 대신 의미 색상 토큰을 사용하고, 선명한 화면 모드는 [data-krds-mode=high-contrast] 선택자에서 --krds-high-contrast-color-*로 바꿔 지정한다.
