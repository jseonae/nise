글꼴

표준형 스타일은 국문과 영문 모두 Pretendard GOV 서체를 기본으로 사용한다. 확장형은 가독성이 높은 고딕 계열 서체(노토 산스, 나눔 고딕, 스포카 한 산스 등)를 권장한다.

글꼴 기본 토큰과 값
토큰값설명
--krds-font-family-basehtml, body 기본 글꼴 (--krds-typo-font-type 참조). @font-face는 _common/resources/css/krds-custom.css에 정의
--krds-font-size-basehtml 글자 크기. 브라우저 기본 16px 기준 1rem = 10px
--krds-pc-font-size-body-mediumbody 기본 글자 크기. 본문 최소 16px 이상, Pretendard GOV는 상대적으로 작아 17px을 기본으로 한다

크기는 다양한 글자 크기 설정에 대응하도록 px이 아닌 rem, em, % 등 상대 단위를 사용한다.

글자 굵기

텍스트 두께 사용은 최대 4가지 정도로 제한한다. 지나치게 얇은 두께(light, thin)는 배경과의 구분이 어렵고, 지나치게 두꺼운 두께(extra bold)는 시각적 피로를 유발한다.

Regular 가나다 Aa 123

--krds-font-weight-regular

본문에 사용하여 기본 가독성을 보장한다.

Bold 가나다 Aa 123

--krds-font-weight-bold

강조가 필요한 제목이나 중요한 내용에 사용한다.

줄 간격과 자간

줄 간격은 가독성과 접근성을 위해 최소 150% 이상으로 설정한다. 줄 간격이 좁을수록 시각적 피로를 느끼게 하며 정보 전달의 효율성이 떨어진다.

스타일 토큰

타이포그래피는 display, heading, body로 계층을 구성하고 컴포넌트용 label, navigation을 둔다. 크기는 반응형 토큰으로 PC(--krds-pc-font-size-*)와 모바일(--krds-mobile-font-size-*, 767px 이하)을 나누어 쓴다. 굵기, 줄 간격, 자간은 스타일별 토큰이 없어 KRDS 가이드 표의 값을 표시했다. 코드에서는 굵기 --krds-font-weight-{regular|bold}, 줄 간격 --krds-line-height-base(모든 스타일 150%), 자간 --krds-letter-spacing-{none|wide}를 사용한다.

크기 / 줄 높이 = 토큰 크기 × --krds-line-height-base(1.5)

계층 구조

계층 구조는 사용자에게 정보의 중요도를 명확히 전달한다. 이상적인 heading과 body 간의 글자 크기 차이는 1.25~1.5배로 설정한다. 정보 구조가 단순하면 heading을 단순화할 수 있고, 본문과 heading 크기가 같아지는 구간은 굵기로 구분한다.

제목 요소별 heading 스타일 범위와 사용처
구조스타일 범위사용
h1heading-xlarge ~ large페이지나 섹션의 가장 중요한 제목으로, 주요 주제를 강조하는 데 사용
h2heading-large ~ medium콘텐츠의 주요 섹션을 구분하여 h1보다 작은 부제목 역할
h3heading-medium ~ small세부 섹션을 나타내는 제목으로, h1과 h2보다 작은 크기로 사용
h4heading-small ~ xsmall본문과 비슷한 크기의 제목으로, 세부적인 콘텐츠에 대한 설명에 사용
h5heading-xsmall ~ xxsmall가장 작은 제목으로, 부차적인 정보나 보조 설명을 위해 사용

글자 색상 접근성

글자 색상은 가독성과 접근성을 고려해 사용한다. 본문은 주로 그레이 계열을 유지하며, 색상 토큰은 색상 페이지를 참고한다.

텍스트 크기별 명도 대비 기준
등급큰 텍스트일반 텍스트
AA (최소)3:1 (매직넘버 40)4.5:1 (매직넘버 50)
AAA (강화)4.5:1 (매직넘버 50)7:1 (매직넘버 70)
  • 큰 텍스트: 24px(18pt) 이상, 굵게 표시된 경우 18.66px(14pt) 이상
  • 일반 텍스트: 24px(18pt) 미만, 굵게 표시된 경우 18.66px(14pt) 미만
  • 선명한 화면 모드: 본문 15:1, 헤딩·레이블 등의 텍스트와 아이콘 7:1, 시각적 보조 수단 4.5:1

사용 원칙

  • 타이틀과 본문은 시각적 위계가 유지되도록 한다. 크기가 같으면 두께로 중요도를 구분한다.
  • 밑줄은 텍스트 링크에만 사용하며 강조에 사용하지 않는다. 강조는 색상이나 굵기를 이용한다.
  • 고딕 계열이 아닌 자체 개발 폰트는 디스플레이나 배너에만 사용한다.
  • 화면 코드에서는 px 값 대신 --krds-pc-font-size-*, --krds-mobile-font-size-* 토큰을 사용하고, 767px 이하에서 모바일 토큰으로 바꾼다.
